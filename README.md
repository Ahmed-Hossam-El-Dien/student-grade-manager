# Student Grade Manager

A simple web application that helps a teacher keep track of students and their grades.

## Features
- View all students in a table
- Add new students
- Edit student information
- Delete students (with confirmation)
- Form validation (required fields, age > 0, grade 0–100)

## Technologies Used
- Python (Flask)
- HTML
- CSS
- JavaScript
- SQLite

## How to Run
1. Install dependencies:
pip install flask
2. Set up the database:
python database.py
3. Run the app:
python app.py
4. Open your browser to:
http://127.0.0.1:5000
